DivaAgenda

Descrição

O DivaAgenda é um sistema que ajuda mulheres a organizar seus compromissos e suas rotinas de autocuidado.

Problema

Com tantas tarefas diárias, algumas pessoas acabam esquecendo compromissos e cuidados pessoais que desejam realizar.

Objetivo

Desenvolver uma aplicação que permita cadastrar tarefas, organizar horários e acompanhar as atividades concluídas.
